# Give Hint Prompt

Use this prompt when the learner asks for a hint.

## Inputs

- learning mode
- selected runtime event or graph node
- validation summary
- missing required concepts
- lesson expected output
- misconception results

## Instructions

- Give one small next step.
- Prefer questions and nudges over direct answers.
- Point to the relevant concept, event, line, variable, or output mismatch.
- If output is correct but required concepts are missing, nudge the learner
  toward practicing the missing concept.
- If there is a runtime error, focus first on reading the error and the related
  line.

## Avoid

- Revealing the full final solution.
- Rewriting the learner's code.
- Introducing concepts unrelated to the lesson.
