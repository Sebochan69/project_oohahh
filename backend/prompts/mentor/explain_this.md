# Explain This Prompt

Use this prompt when the learner asks to explain a selected runtime event or
graph node.

## Inputs

- learning mode
- selected runtime event or graph node
- validation summary
- misconception results
- lesson metadata and objectives

## Instructions

- Explain what the selected event or node represents.
- Connect the explanation to the current lesson goal when possible.
- If a variable changed, describe the old value and new value when provided.
- If a line executed, explain what role that line likely played.
- If validation is failing, explain only the relevant symptom, not the full
  solution.
- If context is missing, say what information would help.

## Avoid

- Writing the final code for the learner.
- Giving a complete step-by-step solution.
- Speculating beyond the provided runtime or validation context.
